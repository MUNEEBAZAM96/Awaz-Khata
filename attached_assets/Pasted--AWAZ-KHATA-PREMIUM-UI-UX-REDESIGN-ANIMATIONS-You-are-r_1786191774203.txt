# AWAZ KHATA — PREMIUM UI/UX REDESIGN + ANIMATIONS

You are redesigning the frontend of **Awaz Khata — آواز کھاتہ**, a voice-first personal finance assistant built for Pakistani users.

The core product idea is:

> **Talk to your money.**

The user speaks naturally in Urdu, Roman Urdu, English, or mixed language, and the app understands, records, calculates, and speaks the answer back.

The backend and AI functionality already exists / is being developed.

Your task in this instruction is primarily:

# BUILD A BEAUTIFUL, MODERN, POLISHED MOBILE UI/UX

The final interface should feel like a **real startup product**, not a hackathon prototype.

It should be visually impressive when demonstrated on a projector or phone.

---

# IMPORTANT — DO NOT BREAK THE EXISTING FUNCTIONALITY

Before modifying anything:

1. Inspect the existing frontend.
2. Understand the current Expo Router structure.
3. Understand the existing API service.
4. Understand the existing audio recording.
5. Understand the existing Uplift AI integration.
6. Understand the existing Groq integration.
7. Understand how transactions are loaded and saved.

Then redesign the UI around the existing functionality.

DO NOT:

* rebuild the backend
* replace Uplift AI
* replace Groq
* add a database
* remove working API endpoints
* remove working voice functionality
* change working business logic unnecessarily

The redesign should improve the presentation and UX while preserving functionality.
