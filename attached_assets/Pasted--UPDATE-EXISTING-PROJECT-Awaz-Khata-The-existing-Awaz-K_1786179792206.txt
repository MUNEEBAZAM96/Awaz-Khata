# UPDATE EXISTING PROJECT — آواز کھاتہ (Awaz Khata)

The existing **Awaz Khata** project is already working correctly.

**IMPORTANT: DO NOT rebuild the project from scratch.**

Do not replace the existing architecture, backend, Uplift AI integration, Groq integration, transaction storage, or working voice pipeline unless absolutely necessary.

The current core flow is already working:

**User speaks → Uplift STT → Groq understands → transaction/query processed → Uplift TTS → user hears response**

Your job now is to **upgrade the existing application** and make it feel like a polished, hackathon-winning voice-first personal finance assistant.

The focus of this update is:

1. Better UI/UX
2. Bottom tab navigation
3. Better voice interaction
4. Conversational Urdu voice confirmations
5. Calendar-based transaction history
6. Better transaction/activity experience
7. Better visual feedback while the app is listening/processing/speaking
8. Keep everything simple and reliable for a live hackathon demo

---

## App Name

**آواز کھاتہ**

> **A voice-first personal finance assistant made specifically for Pakistan.**

# 1. NEW PRIMARY VOICE EXPERIENCE

The biggest improvement is to make the voice interaction feel like a real conversation.

Currently the user:

**speaks → app processes → app responds**

Upgrade this so the experience feels like:

### User

> "میں نے علی کو دو ہزار روپے دیے۔"

### App listens

> **"سن رہا ہوں..."**

Then after recording finishes:

### App should speak:

> **"جی، میں نے سن لیا۔"**

Then process the transaction.

After successfully saving:

> **"اور کھاتے میں ڈال دیا ہے۔"**

Or combine them naturally:

> **"جی، میں نے سن لیا اور کھاتے میں ڈال دیا ہے۔"**

The exact wording can vary naturally.

The important thing is that the user should receive **immediate voice acknowledgment** after speaking.

---

# 2. VOICE CONVERSATION STATES

Implement a clear state machine:

```ts
type VoiceState =
  | "idle"
  | "listening"
  | "acknowledging"
  | "processing"
  | "speaking"
  | "error";
```

### IDLE

Display:

> **بولنے کے لیے دبائیں**

### LISTENING

Display:

> **سن رہا ہوں...**

Animate the microphone subtly.

### ACKNOWLEDGING

Immediately after recording stops:

The app should speak a short acknowledgement such as:

> **"جی، میں نے سن لیا۔"**

This should happen quickly.

### PROCESSING

Display:

> **آپ کی بات سمجھ رہا ہوں...**

### SAVING

Display:

> **کھاتے میں شامل کر رہا ہوں...**

### SPEAKING

Display:

> **جواب دے رہا ہوں...**

### ERROR

Display:

> **معذرت، میں سمجھ نہیں سکا۔ دوبارہ بولیں۔**

Then automatically return to:

```text
idle
```

# 3. IMPORTANT — DO NOT DELAY THE ACKNOWLEDGEMENT

The acknowledgement should make the experience feel conversational.

The flow should become:

```text
USER SPEAKS
      ↓
RECORDING STOPS
      ↓
"جی، میں نے سن لیا۔"
      ↓
STT
      ↓
GROQ
      ↓
FINANCE ENGINE
      ↓
"اور کھاتے میں ڈال دیا ہے۔"
```

However, avoid making the user wait unnecessarily.

If possible, play the acknowledgement immediately while the backend processing happens in parallel.

For example:

```text
Recording stopped
       ↓
Immediately play:
"جی، میں نے سن لیا۔"
       ↓
Meanwhile:
Uplift STT
       ↓
Groq
       ↓
Finance engine
       ↓
Final response
```

This is important for the live demo.
